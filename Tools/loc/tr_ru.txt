# Russe (Русский) - "ты", registre de jeu russe naturel. Numéros = skeleton.txt.
# IMPORTANT : en russe, le passé s'accorde au genre du joueur (продержался / продержалась) : formulations NEUTRES
# uniquement (présent, impératif, tournures impersonnelles, "X: {0}" pour les nombres, dont l'accord a 3 formes).
# Glossaire : Or=Золото, Éclats=Осколки, Ultime=Ульта, Dash=Рывок, Clone spectral=Призрачный клон,
# Orbitaux=Спутники, Orbites=Орбиты, Nova=Нова, partie=забег, boss=босс, PV=здоровье (unité compacte : ХП/с ; pas « ОЗ », qui se lit « 03 » en Bangers),
# Réputation=Репутация, skin=скин, compétence=навык, défi=испытание, Fusion=Слияние.
# Noms Aether / Kael / Lyra : gardés en latin et non déclinés (comme dans le reste du jeu).
# Typo : guillemets « », tiret cadratin « — », lettre ё écrite partout où elle se prononce.
# Mots accordés au nombre par le code (Loc.PluralWord) : "Éclat"/"Éclats" après « Не хватает » = génitif
# (1, 21... осколка / 2-4, 5+ осколков), "victoire"/"victoires" (+ forme #few en fin de fichier).
