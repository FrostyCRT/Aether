Le 2026-10-25, l'utilisateur trouvait que Bangers partout faisait « brouillon », pas « jeu pro / triple A ». Décision validée par lui :
- **Bangers** : titres, onglets, boutons, noms (héros, armes, compétences, cartes), gros chiffres, étiquettes courtes en majuscules.
- **Fira Sans SemiBold** (choisie par moi parmi Fira / Nunito / Noto Sans, l'utilisateur m'a fait confiance) : toute phrase (descriptions, infobulles, sous-titres, notes, lignes d'info des écrans de fin, aides des paramètres). Asset `Assets/Resources/Fonts/FiraSans-SemiBold SDF.asset`, accès code `GameFonts.Body` / `GameFonts.ToBody` / `GameFonts.Outline` (contours divisés par 2 sur Fira, sinon le trait fin est rongé).
- Les nombres de dégâts restent en LiberationSans (préférence explicite de l'utilisateur).
- Ponctuation (règle de l'utilisateur, 2026-10-25) : point final sur tout texte long qui contient une virgule ou plusieurs phrases, et sur TOUTES les descriptions de l'arbre de compétences ; pas de point sur les fragments courts. Exception voulue : les descriptions des Paramètres n'ont jamais de point (SettingsSchema.NoFinalStop les retire à l'affichage). La ponctuation finale de chaque traduction suit celle du français (passe faite sur les 9 tr_xx.txt, puis sur LocTableEN.cs le 2026-10-26 : l'anglais, édité à la main, avait 27 points en trop - penser à lui). Contrôle complet des règles : script check_rules.py (comparaison skeleton/tr_xx) refait à la demande de l'utilisateur ; faux positifs connus : points latins du coréen (convertis au build), majuscules initiales dues à la grammaire.
- Ton des textes de menu : professionnel, pas familier (ex. « pour de bon » refusé). Messages de page dans une pastille sombre (composant HintPill, même rendu que la consigne de l'arbre).

- Depuis le 2026-10-25, `TextBalancer` (global, via TMPro_EventManager.TEXT_CHANGED_EVENT) équilibre les lignes des TextMeshProUGUI multi-lignes CENTRÉS uniquement (choix utilisateur : les paragraphes alignés à gauche, ex. fiche de l'arbre, gardent toute la largeur ; marges resserrées, même nombre de lignes et même taille ; marges remises + régénération en LateUpdate sinon le layout mesure à l'ancienne largeur) et met des insécables dans les parenthèses et avant « : ; ! ? % » (balises <nobr>, pas U+00A0 : TMP ne l'élargit pas en Justifié). Depuis le 2026-10-26 (demande utilisateur), tout paragraphe Fira ALIGNÉ À GAUCHE de 3 lignes ou plus passe en Justifié (espaces entre mots seulement ; le Justifié TMP peut resserrer un texte de 3 à 2 lignes, accepté ; garde-fou MaxJustifyStretch = 0,55 em d'élargissement par espace, au-delà le paragraphe reste à gauche : demande utilisateur du 2026-10-26 sur « Bouclier de Mana », trous jugés bizarres ; justifiés validés ≤ 0,38 em). Textes centrés (cartes de montée de niveau/fusion) exclus par choix de l'utilisateur : trop de trous avec 4-5 mots par ligne, ils restent centrés et équilibrés. Cartes de montée de niveau CLASSIQUES (hors fusion) : description sur 2 lignes maximum (demande utilisateur 2026-10-26), boîte 350 px pour classiques ET fusions (380 jugé trop large par l'utilisateur), police calée par TextBalancer.FitToLines (28 → 18) ; textes longs raccourcis dans les 11 langues. Fusions : taille 26, 3 lignes MAXIMUM (4 jugé trop par l'utilisateur le 2026-10-26) : textes raccourcis dans les langues qui dépassaient, FitToLines(3) en filet de sécurité. Icônes des deux types de carte au même Y (CardIconY). La description de la carte du milieu avait des marges négatives dans Game.unity (remises à 0 le 2026-10-26). Tout nouveau texte de carte doit tenir en 2 lignes. Demande utilisateur : lignes de longueur égale, jamais une parenthèse coupée entre deux lignes. Si un texte se comporte bizarrement (marges qui bougent), c'est la première piste.

**Why:** couple « police d'affiche + police de lecture » des jeux pro (LoL Beaufort/Spiegel, Overwatch, Hearthstone) ; Bangers n'a que des majuscules penchées, illisible en petit.

**How to apply:** tout nouveau texte-phrase → Fira ; tout nouveau titre/nom/bouton → Bangers. Piège : en enregistrant une scène après `t.font = fira` via RunCommand, TMP a remis LiberationSans dans m_fontAsset (le matériau Fira restait) - vérifier le guid dans le .unity après chaque sauvegarde. Modifier un .unity sur disque pendant qu'il est ouvert bloque Unity sur une fenêtre de rechargement. Voir aussi [[project-english-localization]].

- Level up, compétences de base (2026-10-26) : une seule taille de description pour toutes les cartes du tirage (la plus petite qui tient en 2 lignes), centré pleine largeur, SANS équilibrage des lignes (FitToLines balance:false). Les cartes de fusion gardent leur taille propre et l'équilibrage.
